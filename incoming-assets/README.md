# incoming-assets — drop zone

Upload generated media here (GitHub → this folder → "Add file" → "Upload files",
on the `rebuild` branch). Name each file after its asset ID from
ASSETS-REQUIRED.md:

- air-domain-hero.png (or .jpg — any format is fine)
- land-domain-hero.png
- sea-domain-hero.png
- hero-video.mp4
- og-image.png

Several candidates per asset are welcome — suffix them `-a`, `-b`, `-c`
(e.g. `air-domain-hero-b.png`). Compression, cropping, AVIF/WebP conversion
and wiring into the site are handled from here; originals never ship as-is.
